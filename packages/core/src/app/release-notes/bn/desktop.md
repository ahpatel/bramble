Bramble এখন Windows-এ উপলব্ধ, এবং ডেস্কটপ অ্যাপটি আপনার SSH এজেন্ট হিসেবে কাজ করতে পারে।

- ডেস্কটপ অ্যাপটি এখন Windows 10 এবং 11-এ চলে।
- সেটিংস → সাধারণ-এ “টার্মিনালে আপনার SSH কী ব্যবহার করুন” চালু করুন; এরপর ssh, git এবং scp আপনার ভল্টের SSH কী ব্যবহার করে, এবং প্রাইভেট কী Bramble-এর বাইরে যায় না।
- যখন আপনার ডিভাইসগুলো কখনো একসাথে অনলাইনে থাকে না, তখন একটি মেইলবক্সের মাধ্যমে সিঙ্ক করুন। সেটিংস → সিঙ্ক → মেইলবক্সে Bramble-এর পরিষেবা ব্যবহার করুন (মাসে $2), অথবা নিজের সার্ভার চালান।
- Windows-এ Bramble তার উইন্ডোগুলো স্ক্রিনশট ও স্ক্রিন শেয়ারিংয়ের বাইরে রাখে এবং macOS-কেও একই কাজ করতে অনুরোধ করে। সেটিংস → সাধারণ-এ “স্ক্রিনশট ব্লক করুন” দিয়ে এটি বন্ধ করুন।
- কুইক অ্যাক্সেসে, ⌘T (Windows এবং Linux-এ Ctrl+T) হাইলাইট করা লগইনের 2FA কোড কপি করে।
- macOS-এ, AutoFill-এ আনলক করলে ডেস্কটপ অ্যাপও আনলক হয়ে যায়।
- KeePass-এ এক্সপোর্ট করার সময় একটি লগইনের অতিরিক্ত ওয়েবসাইটগুলো এমন জায়গায় রাখা হয় যেখানে KeePassXC এবং Keepass2Android সেগুলো পড়তে পারে।
