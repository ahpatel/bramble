Synchronisierung über ein Postfach, wenn Ihre Geräte nie gleichzeitig online sind.

- Synchronisieren Sie über ein Postfach, wenn Ihre Geräte nie gleichzeitig online sind. Nutzen Sie Bramble für 2 $ pro Monat oder betreiben Sie Ihren eigenen Server unter Einstellungen → Synchronisierung → Postfach.
- SSH-Schlüssel können die Hosts auflisten, für die sie bestimmt sind, und die Desktop-App kann sie jetzt im Terminal verwenden.
- Beim Export nach KeePass bleiben die zusätzlichen Websites eines Logins dort erhalten, wo KeePassXC und Keepass2Android sie lesen.
- Das Löschen eines von zwei Tresoren aus der Tresorliste öffnet jetzt den verbleibenden Tresor.
- Geräte, die kurz nach der vollen Stunde entsperrt werden, finden sich jetzt sofort.
