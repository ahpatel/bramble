Bramble이 이제 Windows에서 사용 가능하며, 데스크톱 앱을 SSH 에이전트로 사용할 수 있습니다.
- 데스크톱 앱이 이제 Windows 10 및 11에서 실행됩니다.
- 설정 → 일반에서 '터미널에서 SSH 키 사용'을 켜면 ssh, git, scp가 개인 키를 Bramble 밖으로 내보내지 않고 볼트에 있는 SSH 키를 사용합니다.
- 기기가 동시에 온라인 상태가 아닐 때 메일함을 통해 동기화하세요. 설정 → 동기화 → 메일함에서 Bramble 메일함(월 $2)을 사용하거나 자체 서버를 운영하세요.
- Bramble은 Windows에서 창이 스크린샷과 화면 공유에 나타나지 않도록 하며, macOS에도 동일하게 요청합니다. 설정 → 일반의 '스크린샷 차단'에서 끌 수 있습니다.
- 빠른 실행에서 ⌘T(Windows 및 Linux에서는 Ctrl+T)를 누르면 선택된 로그인의 2FA 코드가 복사됩니다.
- macOS에서는 자동 완성에서 잠금을 해제하면 데스크톱 앱도 잠금 해제됩니다.
- KeePass로 내보내면 로그인의 추가 웹사이트가 KeePassXC와 Keepass2Android에서 읽을 수 있도록 유지됩니다.
