Bramble이 이제 스크린샷과 화면 녹화를 차단하고, 메일함을 통해 동기화할 수 있습니다.

- Bramble이 이제 보관함을 스크린샷, 화면 녹화, 화면 미러링으로부터 보호합니다. 스크린샷을 찍으려면 설정 → 일반의 '스크린샷 차단'에서 '10분간 허용'을 선택하십시오.
- 기기가 동시에 온라인 상태가 되지 않는 경우 메일함을 통해 동기화하십시오. 설정 → 동기화 → 메일함에서 Bramble Mailbox 계정 번호로 로그인하거나 자체 서버를 사용하십시오.
- SSH 키에 대상 호스트를 표시할 수 있으며, 이제 데스크톱 앱의 터미널에서 사용할 수 있습니다.
- KeePass로 내보낼 때 KeePassXC와 Keepass2Android가 읽을 수 있도록 로그인의 추가 웹사이트가 유지됩니다.
- 보관함 목록에서 두 보관함 중 하나를 삭제하면 이제 남은 보관함이 열립니다.
- 정각 직후에 잠금 해제된 기기가 이제 서로를 즉시 찾습니다.
