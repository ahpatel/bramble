기기가 동시에 온라인 상태가 아닐 때 메일함을 통해 동기화할 수 있습니다.

- 기기가 동시에 온라인 상태가 아닐 때 메일함을 통해 동기화할 수 있습니다. Bramble 서비스를 월 $2에 이용하거나, 설정 → 동기화 → 메일함에서 자체 서버를 실행할 수 있습니다.
- SSH 키에 연결된 호스트를 나열할 수 있고, 이제 데스크톱 앱에서 해당 키를 터미널에서 사용할 수 있습니다.
- KeePass로 내보낼 때 로그인의 추가 웹사이트가 KeePassXC와 Keepass2Android에서 읽을 수 있는 위치에 유지됩니다.
- 볼트 목록에서 두 개 중 하나를 삭제하면 이제 남은 볼트가 열립니다.
- 정시 직후에 잠금 해제되는 기기들이 이제 즉시 서로를 찾습니다.
