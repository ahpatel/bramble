기기가 동시에 온라인 상태가 되지 않아도 메일함을 통해 동기화할 수 있습니다.

- 기기가 동시에 온라인 상태가 되지 않아도 메일함을 통해 동기화할 수 있습니다. Bramble의 메일함을 월 $2에 이용하거나 자체 서버를 운영할 수 있습니다. 설정 → 동기화 → 메일함에서.
- SSH 키에 대상 호스트를 표시할 수 있으며, 데스크톱 앱에서 이제 터미널에서 사용할 수 있습니다.
- KeePass로 내보낼 때 KeePassXC와 Keepass2Android가 읽는 위치에 로그인 항목의 추가 웹사이트가 유지됩니다.
- 보관함 목록에서 두 보관함 중 하나를 삭제하면 이제 남은 보관함이 열립니다.
- 정각 직후에 잠금 해제하는 기기들이 이제 서로를 바로 찾습니다.
