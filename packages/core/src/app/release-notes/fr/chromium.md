Synchronisez-vous via une boîte aux lettres lorsque vos appareils ne sont jamais en ligne en même temps.

- Synchronisez-vous via une boîte aux lettres lorsque vos appareils ne sont jamais en ligne en même temps. Utilisez celle de Bramble, pour 2 $ par mois, ou lancez votre propre serveur, dans Paramètres → Synchronisation → Boîte aux lettres.
- Les clés SSH peuvent indiquer les hôtes auxquels elles sont destinées, et l'application de bureau peut désormais les utiliser dans le terminal.
- L'exportation vers KeePass conserve les sites web supplémentaires d'un identifiant là où KeePassXC et Keepass2Android peuvent les lire.
- Supprimer l'un des deux coffres-forts de la liste ouvre désormais celui qui reste.
- Les appareils qui se déverrouillent juste après l'heure se trouvent désormais immédiatement.
