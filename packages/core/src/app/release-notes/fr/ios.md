Bramble bloque désormais les captures d’écran et les enregistrements d’écran, et peut se synchroniser via une boîte aux lettres.

- Bramble empêche désormais votre coffre-fort d’apparaître dans les captures d’écran, les enregistrements d’écran et la duplication d’écran. Pour effectuer une capture d’écran, choisissez Autoriser pendant 10 minutes sous Bloquer les captures d’écran dans Paramètres → Général.
- Synchronisez vos appareils via une boîte aux lettres lorsqu’ils ne sont jamais en ligne en même temps : connectez-vous avec un numéro de compte Bramble Mailbox, ou utilisez votre propre serveur, dans Paramètres → Synchronisation → Boîte aux lettres.
- Les clés SSH peuvent indiquer les hôtes auxquels elles sont destinées, et l’application de bureau peut désormais les utiliser dans le terminal.
- L’exportation vers KeePass conserve les sites web supplémentaires d’un identifiant là où KeePassXC et Keepass2Android les lisent.
- La suppression d’un des deux coffres-forts de la liste des coffres-forts ouvre désormais celui qui reste.
- Les appareils qui se déverrouillent juste après l’heure se détectent désormais immédiatement.
